# Personal Ops OAuth site

A minimal, public, static information site for the owner's personal Google Tasks OAuth application. No application code, tokens, or task data belong in this repository.

## Published pages

- Home: https://oldfatcrab.github.io/personal-ops-oauth/
- Privacy policy: https://oldfatcrab.github.io/personal-ops-oauth/privacy.html

## GitHub Pages

The site uses ordinary static HTML/CSS on the `main` branch, repository root. Enable GitHub Pages under **Settings → Pages → Deploy from a branch → main / (root)** if it has not already been enabled.
